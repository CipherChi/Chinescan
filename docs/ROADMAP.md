# Roadmap

- Phase 1: platform foundation, canonical records, local config/logging/storage, CLI contracts.
- Phase 2: authorization and scope workflows.
- Phase 3: scanner adapters and controlled orchestration.
- Phase 4: analysis and enrichment.
- Phase 5: reporting and export.
- Phase 6: additional integrations and automation.
- Phase 7: operational hardening and deployment.
- Phase 8: broader validation, documentation, and release readiness.

Only Phase 1 is implemented here. This roadmap is a scope summary, not a promise that later capabilities are currently available.
