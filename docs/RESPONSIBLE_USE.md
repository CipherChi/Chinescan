# Responsible use

Use ChineScan only for assets and data you own or are explicitly authorized to assess. Keep written scope and authorization records for any later-phase activity. Respect applicable law, service terms, privacy obligations, and rate limits.

Phase 1 does not perform scans, accept malware samples, expose a network service, or provide incident response. A target model is data only; it does not grant permission to interact with a target. Future scanning phases must enforce explicit scope and safe defaults before connecting to external systems.
